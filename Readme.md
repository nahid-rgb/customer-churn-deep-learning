# Customer Churn Prediction Using Deep Learning
A customer churn prediction project using an Artificial Neural Network (ANN) built with TensorFlow and Keras, with Scikit-learn for data preprocessing and Streamlit for deployment.

## Live Demo

[Customer Churn Prediction App](https://customer-churn-deep-learning-8slwxfaykrerauxkejjxvd.streamlit.app/?utm_source=chatgpt.com)

## Technologies Used

* Python
* TensorFlow & Keras
* Scikit-learn
* Pandas
* NumPy
* Streamlit

## Features

* Predicts customer churn using a deep learning model
* Data preprocessing and feature encoding
* Neural network built with TensorFlow and Keras
* Interactive Streamlit web application
* Deployed using Streamlit Community Cloud
